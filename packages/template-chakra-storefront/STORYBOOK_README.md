# Storybook Integration

This package includes a complete Storybook + Vite integration for component development and documentation.

- **[STORYBOOK_DEVELOPER_GUIDE.md](./STORYBOOK_DEVELOPER_GUIDE.md)** - Complete developer guide with setup, usage, and best practices
- **[STORYBOOK_INTEGRATION.md](./STORYBOOK_INTEGRATION.md)** - Integration details and configuration

## 🚀 Quick Start

1. **Navigate to this package:**
   ```bash
   cd packages/template-chakra-storefront
   ```

2. **Start Storybook:**
   ```bash
   npm run storybook
   ```

3. **Access Storybook:**
   Open http://localhost:6006
